# Changelog

## 0.2.1 — 2026-10-11

Release preparation: public installation and contribution documentation, GPL-3.0-or-later licensing and package metadata, CI build/test workflow, and an Orca Cloud publication guide. Calculator source and behavior are unchanged from 0.2.0.

Native profile operation, voltage/current independence, and saved voltage/mode after reopening the calculator have now passed by user report. The new 0.2.1 package still needs a native installation smoke check; Linux/macOS and large-mesh native cancellation remain unverified.

## 0.2.0 — 2026-10-10

- Add 24 bath reference profiles, including non-electrical processes and Custom.
- Add independent constant-current voltage-limit and constant-voltage setpoint fields.
- Preserve legacy copper settings and validate incomplete numeric inputs.
- Keep product-specific references separate from user process settings.

## 0.1.0 — 2026-10-09

Initial local beta: transformed mesh area, per-copy selection and masking, unit conversion, independent running/starting currents, report copying, saved preferences, and OrcaSlicer integration.
