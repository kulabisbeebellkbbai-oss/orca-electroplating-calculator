# Security

The plugin reads loaded mesh geometry and its own resources, stores preferences through OrcaSlicer's configuration API, and offers report copying. It does not send model data over a network or control plating equipment. Orca and its dependency installer have their own permissions and network behavior.

For a vulnerability, use GitHub's **Security → Report a vulnerability** on this repository if available. Before publication, the maintainer should enable private vulnerability reporting. If that option is unavailable, open a minimal issue asking for a private contact without posting exploit details, credentials, or private geometry. Ordinary numerical or compatibility problems belong in Issues with a small non-sensitive reproduction.

Only the latest beta is maintained. No response-time or security-audit certification is claimed. Report limitations and validate process inputs independently before relying on a calculated setting.
